Language Documentation

A statically typed, C-style programming language designed around explicit declarations, predictable syntax, and minimal historical baggage.

Variables

Variables are declared using let. Every declaration must explicitly specify whether the variable is mutable or constant.

let mut int x = 10;
let const int y = 20;

Mutable variables can be reassigned with set:

let mut int x = 10;

set x = 12;

Reassignment does not change the variable's type:

let mut int x = 10;

set x = 12;       // valid
set x = "hello";  // invalid

A declaration without a mutability modifier is invalid:

let int x = 10; // invalid

The language does not assume mutability or immutability. The programmer must explicitly choose.

Shadowing

Variables may shadow existing variables, including variables with the same name and in the same scope.

let mut int x = 10;

let const int x = 20;

set x = 30; // invalid

The second x shadows the first x. The active x is therefore the constant.

The language does not restrict what can be shadowed. Yes, this means you can do things that make future-you question your life choices.

Type Inference

Type inference is explicitly requested using auto.

let mut auto x = 5;
let const auto name = "hello";

auto determines the type from the value provided during initialization.

Explicit types remain available:

let mut int x = 5;

This distinction allows programmers to choose between explicit typing and inference.

Assignment

Variables are modified using set.

set x = 15;

A constant cannot be modified:

let const int x = 10;

set x = 15; // invalid

Conditionals

Conditional statements use C-style blocks.

if(condition){
    io.conout("true");
}else if(other_condition){
    io.conout("other");
}else{
    io.conout("false");
};

The semicolon terminates the entire conditional chain.

An if without an else is terminated directly:

if(condition){
    io.conout("true");
};

When an else follows, the semicolon belongs after the complete chain.

Loops

while loops repeatedly execute while their condition is true.

while(condition){
    io.conout("running");
};

for loops iterate over a collection.

for(item) in(items){
    io.conout(item);
};

Here, item represents the current element and items represents the collection being iterated over.

Functions

Functions are declared using fn.

fn int foo(){
    return(10);
};

The return type appears before the function name.

Functions are constant by default, so there is no need to specify const on the function itself.

Function parameters use normal variable declarations:

fn int foo(let const auto bar){
    return(1);
};

Multiple parameter types are supported:

fn int add(let const int a, let const int b){
    return(a + b);
};

The auto type allows a parameter to accept values whose type is determined dynamically:

fn int foo(let const auto bar){
    return(bar + 1);
};

Operations performed on an auto value may fail if the supplied value does not support that operation.

For example, passing a string to the function above would cause the addition operation to fail.

Return Values

Functions return values using return.

fn string cat_floofiness(let const bool fluffy){
    if(fluffy){
        return("verily");
    }else{
        return("sadly not");
    };
};

Function return values are ordinary values. A function does not need a mut return modifier because the caller receives its own value.

Console Output

Console output is provided through io.conout.

io.conout("Hello, world!");

Values can also be printed:

let const string message = "hello";

io.conout(message);

Imports

External modules or libraries are included using include().

include("math");

Unlike C's preprocessor-based #include, include() is part of the language syntax itself.

Error Handling

Errors can be handled using try, catch, and finally.

A try block does not require a catch or finally:

try{
    something_that_might_fail();
};

If the operation fails and there is no catch or finally, the failure is silently ignored.

A catch block can handle the failure:

try{
    something_that_might_fail();
}catch(error){
    io.conout(error);
};

A finally block runs after the try operation regardless of whether it succeeds or fails:

try{
    something_that_might_fail();
}finally{
    cleanup();
};

Both can be used together:

try{
    something_that_might_fail();
}catch(error){
    io.conout(error);
}finally{
    cleanup();
};

Design Philosophy

The language is intentionally explicit.

Mutability must be declared:

let mut int x = 10;

Assignment is explicit:

set x = 20;

Type inference must be requested:

let mut auto x = 10;

Functions have explicit return types:

fn int foo(){
    return(10);
};

The syntax is deliberately familiar to programmers coming from C-family languages, while avoiding some of C's historical baggage.

In short:

C, but more pedantic and with significantly fewer ghosts from 1972.
