Design Philosophy

The language is designed to sit between high-level and low-levelprogramming.

Memory allocation and lifetime management are handled by the language, but the programmer is expected to understand the distinction between storage and the value stored in that storage.

The language favors explicit syntax over implicit behavior. Types, mutability, value access, assignment, function return types, and function parameters are all visible in the source code.

The language is intentionally verbose when that verbosity communicates useful information.

Program Structure

A program consists of declarations and statements. Functions are declared using the fn keyword. 

fn int main(){
    io.conout("Hello, world!");
    return(0);
};

main is the entry point of the program.

Compound constructs such as functions, conditionals, loops, and exception handlers are terminated with a semicolon after their closing brace.

Variables

Variables are declared with let, followed by their mutability, type, name, and optional initial value. 

let mut int x=10;
let const string y="hello";

Mutable variables

A variable declared with mut may be modified after declaration. 

let mut int score=100;
set score=get(score)+10;

Constant variables

A variable declared with const cannot be modified through that binding. 

let const string name="Alice";

Constant may be shadowed by a new declaration with the same name to reassign, although this is generally discouraged in favor of using a mutable variable to start with. 

let const string name="Alice";
io.conout(get(name));
let const string name="Bob";
io.conout(get(name));

Shadowing

A declaration may shadow another declaration with the same name. Shadowing may also change the type associated with that name. 

let const int x=10;
io.conout(get(x));
let const string x="hello";
io.conout(get(x));

This prints:

10
hello

Storage Access

Variables represent storage. The get operation retrieves the value stored there. 

let const int x=10;


        io.conout(get(x));

Assignment is performed using set. 

let mut int x=10;


        set x=get(x)+5;

The distinction between a variable and its stored value is an intentional part of the language.

Functions

Functions use the following general form: 

fn <return type> <name>(<parameters>){
        <statements>


        };

Parameters use the same declaration syntax as local variables. 

fn int add(let const int a,let const int b){
        return(get(a)+get(b));


        };

Functions return values with return. 

return(get(a)+get(b));

Function calls

let const int x=10;


        let const int y=20;

        let const int result=add(x,y);

Conditionals

Conditional execution uses if, else if, and else. 

if(get(temperature)>80){
        io.conout("hot");


        }else if(get(temperature)<40){
        io.conout("cold");
        }else{
        io.conout("comfortable");
        };

Vectors

Vectors contain multiple values of a specified type. 

let const vector[int] numbers=[1,2,3,4,5];

Vector types can be nested. 

vector[vector[int]]

Vectors can be iterated with a for-in loop. 

for(let mut int number) in(get(numbers)){
        io.conout(get(number));


        };

Exception Handling

Exceptions are handled with try, catch, and finally. 

try{
        do_something_risky();


        }catch(let const error error){
        io.conerr("Something went wrong:");
        io.conerr(get(error));
        }finally{
        io.conout("Finished.");
        };

The caught error is represented as a typed, constant binding.

The finally block executes after the try operation regardless of whether an exception was caught.

Standard Library

Console output

Normal console output uses io.conout. 

io.conout("Hello, world!");

Console error output

Error output uses io.conerr. 

io.conerr("Something went wrong.");

String conversion

Values can be converted to strings with str. 

str(get(age))

String joining

Strings can be combined using join. 

"".join([
        get(name),
        ", age ",
        str(get(age))


        ])

Ranges

range(start,end) creates an iterable sequence with an exclusive upper bound.
