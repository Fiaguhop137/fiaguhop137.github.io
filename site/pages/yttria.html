Design Philosophy

The language is designed to sit between high-level and low-level programming.

Memory allocation and lifetime management are handled by the language, but the programmer is expected to understand the distinction between storage and the value stored in that storage.

The language favors explicit syntax over implicit behavior. Types, mutability, value access, assignment, function return types, and function parameters are all visible in the source code.

The language is intentionally verbose when that verbosity communicates useful information.

Program Structure

A program consists of declarations and statements. Functions are declared using the fun keyword. 

fun uint8 main(){
    io.console.output("Hello, world!");
    return(0);
};

main is the entry point of the program.

Yttria source files use the .ytr file extension. The Yttria compiler translates .ytr source files into JavaScript.

Compound constructs such as functions, conditionals, loops, and exception handlers are terminated with a semicolon after their closing brace.

Comments are denoted by two forward slashes (//) and extend to the end of the line. They can also be denoted with /* */ for multi-line comments.

Variables

Variables are declared with let, followed by their mutability, type, name, and optional initial value. 

let mut sint32 x=10;
let const string y="hello";

Mutable variables

A variable declared with mut may be modified after declaration. 

let mut sint32 score=100;
set score=get(score)+10;

Constant variables

A variable declared with const cannot be modified through that binding. 

let const string name="Alice";

A constant binding cannot be modified after declaration. A new declaration may shadow it with the same name, creating a separate binding, although this is generally discouraged in favor of using a mutable variable to start with. 

let const string name="Alice";
io.console.output(get(name));
let const string name="Bob";
io.console.output(get(name));

Shadowing

A declaration may shadow another declaration with the same name. Shadowing may also change the type associated with that name. 

let const uint4 x=10;
io.console.output("".join([str(get(x)),'\n']));
let const string x="hello";
io.console.output(get(x));

This prints:

10
hello

Storage Access

Variables represent storage. The get operation retrieves the value stored there.

A variable expression refers to its storage location. The get operation retrieves the value stored at that location, leaving it out returns a pointer to the storage location, which is usually undesirable behavior. 

let const uint4 x=10;
io.console.output(get(x)); // Prints 10
io.console.output(x); // Prints the pointer(e.g., 0x7fff5fbff6d0)

Assignment is performed using set.

let mut sint32 x=10;
set x=get(x)+5;

The distinction between a variable and its stored value is an intentional part of the language.

Functions

Functions use the following general form: 

fun <return type> <name>(<parameters>){
    <statements>
};

Parameters use the same declaration syntax as local variables.

Function arguments bind to storage locations. Inside the function, use get to retrieve an argument's value.

fun sint32 add(let const sint32 a,let const sint32 b){
    return(get(a)+get(b));
};

Functions return values with return.

return(get(a)+get(b));

Function calls

Functions are called by name with arguments in parentheses.

For example:

let const uint8 x=10;
let const uint8 y=20;
let const uint8 result=add(x,y);

Conditionals

Conditional execution uses if, else if, and else. 

if(get(temperature)>80){
    io.console.output("hot");
}else if(get(temperature)<40){
    io.console.output("cold");
}else{
    io.console.output("comfortable");
};

Switch statements can also be used for more complex conditional logic.

switch(get(temperature)){
    case(80){
        io.console.output("hot");
    }case(40){
        io.console.output("cold");
    }default{
        io.console.output("comfortable");
    };
};

Loops

While

A while loop executes a block of code repeatedly while a condition is true. 

let mut uint4 count=1;
while(get(count)<=5){
    io.console.output(get(count));
    set count=get(count)+1;
};

For-in

A for loop iterates over a value using in. 

for(let const sint32 number) in(get(numbers)){
    io.console.output(get(number));
};

Vectors

Vectors contain multiple values of a specified type. 

let const vector[sint32] numbers=[1,2,3,4,5];

Vector types can be nested. 

vector[vector[sint32]]

Vectors can be iterated with a for-in loop. 

for(let const sint32 number) in(get(numbers)){
    io.console.output(get(number));
};

Exception Handling

Exceptions are handled with try, catch, and finally. 

try{
    do_something_risky();
}catch(let const string error){
    io.console.error("Something went wrong:");
    io.console.error(get(error));
}finally{
    io.console.output("Finished.");
};

The caught error is represented as a typed, constant binding.

The finally block executes after the try operation regardless of whether an exception was caught.

Standard Library

Console I/O

Normal console output uses io.console.output. 

io.console.output("Hello, world!");

io.console.output appends its argument to the output buffer without automatically appending a newline.

Flushing console output

io.console.output appends text to the output buffer. Use io.console.flush with one char argument to write the buffered output to the console, clear the buffer, and then write that character.

io.console.output("Hello, ");
io.console.output("world!");
io.console.flush("\n");

The example writes Hello, world!, appends a newline, and then empties the output buffer.

Console error output

Error output uses io.console.error. 

io.console.error("Something went wrong.");

io.console.error writes its argument to standard error without automatically appending a newline.

Console input

Console input uses io.console.input. 

let const string name=io.console.input("Enter your name: ");

This prompts the user for input and stores the result in a constant string variable.

String conversion

Values can be converted to strings with str. 

str(get(age))

String joining

Strings can be combined using join. 

"".join([get(name),", age ",str(get(age))])

All elements supplied to join must be strings.

Range

range(start,end) produces a vector of integers beginning at start and ending before end. 

range(2,6)

produces: 

2
3
4
5

Range includes the start value but excludes the end value.

Complete Example

The following program demonstrates functions, variables, vectors, iteration, arithmetic, and console output. 

fun sint32 factorial(let const sint32 n){
    let mut sint32 result=1;
    for(let const sint32 iterator) in(range(2,get(n)+1)){
        set result=get(result)*get(iterator);
    };
    return(get(result));
};
fun uint8 main(){
    let const sint32 number=5;
    let const sint32 result=factorial(number);
    io.console.output("Factorial: ");
    io.console.output(get(result));
    return(0);
};

Output: 

Factorial: 120
