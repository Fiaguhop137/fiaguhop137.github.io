Welcome to the eXtensible Markup Programming Language!

Language Primitives

Logic

<if>

Conditionally execute code based on a boolean expression held in <condition>

<if> takes a boolean expression and executes the code within its <then> block if the expression is true

<condition> is the boolean expression that determines whether the code within the <if> block is executed

It can also have an <else> clause to execute code when the expression is false

<while>

Repeatedly execute code while a boolean expression is true

<while> takes a boolean expression(<condition>) and executes the code within its <do> block as long as the expression is true

The expression is evaluated before each iteration of the loop

<equal>

Compare two values for equality

<equal> takes two values and returns a boolean indicating whether they are equal

Variables

<let>

Declare a variable and optionally assign it a value

<let> takes <mut>, <type>, and <name> attributes to declare a variable

<mut> is a boolean value that determines whether the variable is mutable or immutable

<type> is the data type of the variable

<name> is the name of the variable

<let> can also hold an element to assign an initial value to the variable

<set>

Assign a new value to an existing variable

<set> takes a <name> attribute to assign a new value to an existing variable

Variables with mut=false are immutable and cannot be modified after creation

<get>

Retrieve the value of a variable

<get> takes a <name> attribute to retrieve the value of an existing variable

Literals

<cast>

Convert a value to a different type

<cast> takes a <type> attribute to specify the target type and an element to specify the value to convert

For example, <cast type="int"><get name="my_string"/></cast> would convert the value of the variable "my_string" to an integer

<int>

Represent an integer literal

<int> takes the element content to specify that it is an integer

<string>

Represent a string literal

<string> takes the element content to specify that it is a string

Functions

<define>

Define a function with a name, arguments, and a body

<name> is an element to specify the name of the function

<arguments> is a list of <argument> elements that specify the name and type of each argument

Placing an element inside <arguments> sets a default value for that argument if no value is provided when the function is called

An argument of type code can contain executable code that can be executed by the <exec> function

<body> is the code that is executed when the function is called

<return>

Return a value from a function

<return> takes a value to return from the function

Mathematics

<subtract>

Subtract two numbers

<subtract> takes two numbers and returns their difference

<add>

Surprisingly enough, add isn't actually a built-in operator in this language!

It can, however, be found in the math import

Speaking of imports...

Primitives vs. Libraries

XMPL intentionally keeps the set of language primitives small

Primitives are operations directly understood by the compiler

Higher-level operations can be implemented using those primitives and provided through imports

For example, <subtract> is a primitive, while addition is implemented in the math namespace using subtraction

Imports

XMPL has a built-in import system that allows you to import functions from other files

<import> takes a <namespace> attribute to specify the namespace of the imported functions

Once imported, functions can be called using their element name with the namespace attribute

Examples and Standard Libraries

XMPL comes with a standard library of functions that can be imported and used in your code

For example, the math library provides functions for basic arithmetic operations, as well as more advanced mathematical functions

There are also example programs provided in the xmpl directory that demonstrate how to use the language and its standard libraries.

These examples can serve as a starting point for creating your own programs in XMPL.
